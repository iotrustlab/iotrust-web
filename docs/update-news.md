# Updating News

Before editing news, create a PR branch from the latest `main`:

```bash
git switch main
git pull
git switch -c add-news-item
git branch --show-current   # should not print "main"
```

Do not edit news directly on `main`. See [pull-request-workflow.md](pull-request-workflow.md) for the full flow.

News posts live in:

```text
src/data/news.json
```

They appear on:

- Homepage news section
- `/news`
- `/news/<id>`
- SEO/Open Graph metadata

The newest post by `date` becomes the lead story.

## Add A News Post

Add an object to the array in `src/data/news.json`.

Minimal post:

```json
{
  "id": "2026-example-news",
  "title": "IoTrust Lab Shares Example News",
  "date": "2026-06-06",
  "tags": ["Award", "Research"],
  "summary": "One concise sentence that explains the update.",
  "image": "",
  "links": [
    {
      "label": "Related page",
      "url": "/people/lag"
    }
  ]
}
```

Long-form post:

```json
{
  "id": "2026-example-interview",
  "title": "Luis Garcia Discusses CPS Security on Example Radio",
  "date": "2026-06-06",
  "tags": ["Media", "CPS Security"],
  "summary": "Luis Garcia joined an interview to discuss trustworthy cyber-physical systems.",
  "body": [
    "First paragraph of the article.",
    "Second paragraph of the article."
  ],
  "image": "/images/news/example-interview.jpg",
  "imageLayout": "portrait",
  "socialImage": "/images/social/example-interview-og.png",
  "links": [
    {
      "label": "Listen to the interview",
      "url": "https://example.org/interview"
    }
  ]
}
```

## Fields

| Field | Required | Notes |
| --- | --- | --- |
| `id` | yes | URL slug under `/news/<id>` |
| `title` | yes | News headline |
| `date` | yes | `YYYY-MM-DD` |
| `tags` | yes | Short labels |
| `summary` | yes | Used on index pages and metadata |
| `body` | no | Array of article paragraphs for detail page |
| `image` | no | News image path; empty string is allowed |
| `imageLayout` | no | Use `"portrait"` for portrait-style lead images |
| `socialImage` | no | Open Graph image override |
| `links` | no | Related links |

## Writing Guidelines

- Keep the summary short and factual.
- Use `body` only when there is enough substance for an article.
- Put the most important point in the first paragraph.
- Avoid internal process details.
- Avoid claims that need private context to verify.
- Link to public sources when available.

## Images

News images live in:

```text
public/images/news/
```

Use:

```json
"image": "/images/news/example.jpg"
```

If the image is a headshot or tall portrait, add:

```json
"imageLayout": "portrait"
```

Open Graph images normally live in:

```text
public/images/social/
```

Most social images are generated by:

```bash
npm run generate:og
```

`npm run build` runs this automatically.

## Links

Internal links can be root-relative:

```json
{ "label": "Luis Garcia profile", "url": "/people/lag" }
```

External links should be full URLs:

```json
{ "label": "External article", "url": "https://example.org/article" }
```

## Checks

```bash
npm run lint:links
npm run build
```

Common failures:

- Invalid JSON comma or quote.
- News image path does not exist.
- Duplicate news ID.
- Date is not in `YYYY-MM-DD` format.
