Step 3

Play the incident

  1. Press Space (or Play / pause) to run the replay. Change speed with the 1×/4×/10× buttons.

Step 4

See what SPHERE gives each team

For the exercise, SPHERE builds each team its own copy of a utility plant: six virtual machines on their own network, created from one short model file. A team investigates its plant with the same tools an operator or an engineer would use.

Each team gets

  • A PLC running the utility’s control program on OpenPLC.
  • A second OpenPLC, proc, playing the physical plant over its own field link.
  • An HMI that polls the PLC over Modbus/TCP, so every poll crosses the firewall.
  • An engineering workstation and a DMZ gateway, each in its own zone.
  • A firewall where the zones meet: teams write rules there, and its traffic is captured as evidence.
  • An XDC, the team’s way in.

Eleven of these plants run at once, one per team plus a staff test copy.

The model file SPHERE builds from

fw   = vm("fw", 2, 2)      # zone firewall
ews  = vm("ews", 2, 4)     # engineering workstation
hmi  = vm("hmi", 2, 2)     # operator screen
plc  = vm("plc", 2, 2)     # OpenPLC: the controller
proc = vm("proc", 1, 2)    # OpenPLC: the plant simulator
dmz  = vm("dmz", 1, 2)     # third-party gateway

zone(ews, ...); zone(plc, ...); zone(hmi, ...); zone(dmz, ...)   # each zone meets only at fw
field = net.connect([plc, proc])                                    # the field link
experiment(net)

Expected: you can trace an HMI poll from the operator screen, through the firewall, to the PLC, and say where its traffic is captured.

The replay in steps 1–3 is the course’s authored record of each incident. The team plants run the same three utilities live.
